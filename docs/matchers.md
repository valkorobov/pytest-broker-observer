# Matchers

A matcher checks the payload or the complete `ObservedEvent`. In the sync API,
an expectation returns a value; in the async API, the same call requires `await`.

```python
from event_observer.matchers import all_of, field_equals, on_type, source_equals
from example_pb2 import OperationEvent, COMPLETED

completed = all_of(
    on_type(OperationEvent, field_equals("status", COMPLETED)),
    source_equals("example.events"),
)
event = watcher.wait_for(completed, timeout=5.0)
```

`example_pb2` is your project's module generated by the Protobuf toolchain.
Setting `message_type=OperationEvent` when creating a watcher automatically
sets the decoder and the known type used to validate field paths.

## Available checks

| Function | Check |
|---|---|
| `field_equals("operation_id", "op-42")` | Field equality; nested paths use dots as separators |
| `field_matches("child", matcher)` | Check a nested field's value |
| `has_field("child")` | Explicit field presence |
| `protobuf_partial({"operation_id": "op-42", "status": 2})` | Compare the listed Protobuf fields |
| `predicate(fn)` or a plain `fn` | Synchronous payload predicate |
| `event_predicate(fn)` | Synchronous predicate for the complete event |
| `is_message_type(T)` | Class check; a different class produces a mismatch |
| `on_type(T, matcher)` | Check only the specified type; skip other types |
| `header_equals("correlation-id", b"op-42")` | A single header with an exact name |
| `key_equals(b"key")` | Kafka key or another normalized message key |
| `source_equals("example.events")` | Exact source |
| `trace_id_equals("a" * 32)` | Valid W3C trace ID |
| `all_of(a, b)`, `any_of(a, b)`, `not_(a)` | Three-valued composition |

Paths use Protobuf schema names, rather than JSON aliases. An unknown field
name is rejected when a matcher is bound to known types. For a decoder without
a finite set of types, wrap the structured matcher in `on_type(T, ...)`.

Calling `has_field` on a scalar field with implicit presence raises
`UnsupportedFieldPresenceError`. An absent nested message is not automatically
substituted to match default values.

In `protobuf_partial`, nested messages are compared recursively, repeated
fields as a complete ordered sequence, and maps by the specified keys.
The selected oneof branch must be active. `None` does not mean field absence;
string enum names are not converted to numeric values.

## Predicates and mixed types

```python
from event_observer.matchers import event_predicate, on_type

payload_check = lambda payload: payload.operation_id.startswith("op-")
safe_mixed_check = on_type(OperationEvent, payload_check)
metadata_check = event_predicate(lambda event: event.raw.metadata.get("kafka.partition") == 0)
```

Each user callback receives an independent payload copy. Changes in one
callback do not change the Journal or arguments passed to other branches.

A predicate must return an actual `bool`. Async functions are rejected;
a coroutine, number, or other result raises `InvalidMatcherResultError`.
An ordinary callback exception is wrapped in `MatcherEvaluationError` and
terminates only the current expectation. The original exception is preserved
through chaining.

Callbacks must be short, deterministic, and free of I/O. In sync mode they
run in the runtime thread. A Python callback blocking this thread cannot be
forcibly stopped by a timer.

## Composition and metadata

A matcher returns `MATCH`, `MISMATCH`, or `NOT_APPLICABLE`. For `all_of`,
mismatch takes precedence, followed by not applicable, then match. For
`any_of`, the priority is reversed: match, not applicable, mismatch.
`not_` preserves not applicable. Empty `all_of()` and `any_of()` are prohibited.

`all_of` evaluates every branch and can collect several mismatch reasons.
To protect a callback from a different type, use `on_type`, for example
`on_type(OperationEvent, payload_check)`. `any_of` stops at the first match.

`header_equals` distinguishes an absent, null, and empty header. A duplicate
name raises `MatcherEvaluationError`; names are case-sensitive.
For text, specify the encoding explicitly:

```python
from event_observer.matchers import header_equals

header_equals("correlation-id", "operation-42", encoding="utf-8")
```

Invalid bytes raise an error; replacement decoding is not performed. Trace
correlation uses only validated context; an absent or malformed `traceparent`
produces a mismatch without a Protobuf decoder error.
